0hex01 apt repo

Debian 13 (trixie) · amd64 · GPG-signed

Quick install

curl -fsSL https://0hex01.github.io/0hex01-apt-repo/install.sh | sudo bash

This installs the repo keyring and adds the source, then runs apt update.

Stable — dists/stable/main/binary-amd64

curl -fsSL https://0hex01.github.io/0hex01-apt-repo/0hex01.gpg \
  | sudo tee /usr/share/keyrings/0hex01.gpg

echo 'deb [arch=amd64 signed-by=/usr/share/keyrings/0hex01.gpg] https://0hex01.github.io/0hex01-apt-repo stable main' \
  | sudo tee /etc/apt/sources.list.d/0hex01.list

sudo apt update

Unstable — dists/unstable/main/binary-amd64

Same signing key — if the keyring is already installed, skip the first line.

curl -fsSL https://0hex01.github.io/0hex01-apt-repo-unstable/0hex01.gpg \
  | sudo tee /usr/share/keyrings/0hex01.gpg

echo 'deb [arch=amd64 signed-by=/usr/share/keyrings/0hex01.gpg] https://0hex01.github.io/0hex01-apt-repo-unstable unstable main' \
  | sudo tee /etc/apt/sources.list.d/0hex01-unstable.list

sudo apt update

apt search 0hex01        # list packages
sudo apt install <pkg>
